# Repose TRV

Page terrain installable (iPhone : Partager > Sur l'écran d'accueil) pour saisir la repose des têtes thermostatiques :
code de l'étiquette (pavé, dictée ou photo), lieu, étage.

- Fonctionne sans réseau : la page est mise en cache par le service worker, les saisies et les photos restent sur le téléphone et partent au retour du réseau.
- Aucune donnée dans ce dépôt : la liste des têtes et les saisies passent par une application Web Google Apps Script, protégée par un code d'accès.
